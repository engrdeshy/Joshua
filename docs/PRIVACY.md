# Bible Flourish privacy

Effective September 4, 2026.

Bible Flourish does not create user accounts and does not include advertising, analytics, or crash-reporting trackers. Reading history, notes, highlights, bookmarks, and reminder settings are stored in the app's private on-device storage. Android cloud backup and device-transfer backup are disabled for this data.

The app connects only over HTTPS and uses the network when you choose to download Bible translations, Strong's numbers, or cross-reference data. It does not upload your reading activity or annotations. A manual backup is created only when you request it and choose its destination with Android's system file picker.

The optional daily reading reminder requests notification permission on Android 13 and newer only after you enable the feature. The reminder contains the current book and chapter, is marked private on the lock screen, and can be disabled at any time in Settings.

Permissions used:

- Internet and network state: download Bible resources that you request.
- Notifications: show an optional daily chapter reminder.
- Receive boot completed: restore an enabled reminder after the device restarts.
